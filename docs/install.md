# 安装 / 升级 / 卸载（通用，所有插件都一样）

插件只活在 `plugins/addons/<插件名>/` 这一个目录里，不往 `app/`、`public/` 塞任何东西。
下面拿「公共黑名单」举例，装别的插件把目录名换一下就行。

---

## 一、装

### 1. 拿到插件目录

两个来源，随便挑：

- 官网插件页 <https://aiapizz.com/plugins.php> 下载 zip，解压出来就是一个插件目录（例如 `blacklist/`）；
- 或者 clone 本仓库，用 `plugins/addons/blacklist/` 这个目录。

### 2. 传上去

传到站点根目录的 `plugins/addons/` 下面，最终长这样：

```
站点根目录/plugins/addons/blacklist/BlacklistPlugin.php
站点根目录/plugins/addons/blacklist/info.json
站点根目录/plugins/addons/blacklist/install.sql
站点根目录/plugins/addons/blacklist/lib/ ...
```

三个容易踩的点：

- `addons` 目录不存在 —— 自己建一个就行（有些站是空的，正常的）；
- **别多套一层**：`plugins/addons/blacklist/blacklist/...` 是错的，系统扫不到；
- 传完确认权限、属主跟站里其它目录一致（一般是 `www`）。

### 3. 后台安装

「插件管理」→ 列表里没有就点「**刷新插件列表**」→ 找到它 → **安装** → **启用**。

安装只会动插件自己的东西：

- 建自己的表（表名里的 `pre_` 会按站点自己的表前缀替换，跟系统其它插件一个规矩）；
- 有的插件会往系统的计划任务表里登记一条任务（例如公共黑名单的「公共黑名单同步」，60 秒一轮）。
  那只是**往表里插一条数据**，在「系统管理 - 计划任务」里看得见、能停能启能单跑，不是改文件。

### 4. 配置

`插件管理 → 配置` 里填地址、密钥、开关 —— 需要填什么、每一项什么意思，都在那个表单里写着
（表单是插件 `info.json` 定义的，插件之间不共用）。填完保存。

### 5. 确认它真的在跑

- 左侧菜单出现插件的入口；
- 插件页第一张卡状态不是报错（公共黑名单会写「运行中 / 只上报不拦截 / 上一轮没连上平台 / 还没连上平台」）；
- 带计划任务的插件，去「系统管理 - 计划任务」看一眼那条任务在不在、上次跑成没跑成。

---

## 二、升级

1. 覆盖插件目录（**只覆盖 `plugins/addons/<插件名>/`**，别动别的）；
2. 后台「插件管理」找到它，点一次「**更新**」—— 它会跑 `update.sql`：补建新表、补新字段、
   补上该登记的计划任务。**不点这一步，SQL 不会自己跑，功能就是旧的那套。**
3. 版本号看列表里那一列，跟 `info.json` 的 `version` 一致。

升级不会动你的配置，也不会动你系统里已有的数据。每个版本改了什么见 [../CHANGELOG.md](../CHANGELOG.md)。

---

## 三、卸载

后台「插件管理 → 卸载」。会发生什么：

- 插件自己的表被删掉（`uninstall.sql`）；
- 插件登记的那条计划任务被删掉（**只认任务名和插件名都对得上的行**，系统自己的任务一根汗毛都不碰）；
- **系统原有的黑名单表一个字都不动** —— 包括插件下发进去的那些行。卸载脚本一条都不会删别人的数据，
  所以想清干净就**在卸载之前**去插件页点一次「清空平台已下发条目」。

装的时候没改过任何系统文件，所以卸载之后**不需要恢复任何东西**。

## 四、卡住了怎么查

**插件列表里没有它**
① 路径对不对（`plugins/addons/blacklist/` 里面应该直接就是 `info.json`，别多套一层）；
② 点「刷新插件列表」；③ 目录权限、属主是否跟别的插件一致。

**安装时报 SQL 错**
插件建表脚本里写的是 `pre_` 前缀，系统会按站点自己的表前缀替换。报错一般是数据库账号没有建表权限，
或者站点表前缀被改成了系统不认的形式。把**完整报错原文**发到官方 QQ 群 **439392221**，一眼就能看出来。

**装完左侧菜单没出现**
菜单要挂到系统已有的菜单组上，挂不上时不显示。个别插件的 README 里写了应急办法
（比如把某个 `'parent' => 'TradeManage'` 改成 `''`，它就变成一个顶级菜单项）。

**升级完功能没变**
多半是忘了点「更新」（`update.sql` 没跑）。另外插件配置有缓存，保存配置时系统会自己清；
覆盖文件之后刷新一次后台页面比较稳妥。

**老站：系统没有计划任务表**
`pre_crontab` 是系统 `update5` 之后才有的。老站没有这张表时插件会自动降级 ——
公共黑名单这类插件会给出**插件自备的任务地址**（形如 `你的站/addon/blacklist/task?key=…`），
复制到宝塔 →「计划任务」→ 任务类型选「访问URL」、周期 60 秒，效果和系统计划任务一模一样。
