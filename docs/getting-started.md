# 接入公共黑名单

公共黑名单是「大家共用的一份名单」：你在自己站里拉黑一个人可以报上去；别人报的、平台核实过的，
你也能拉到本地，**在付款时由系统自动拦住**。插件就是它装在你站里的那一头。

- 平台：<https://aiapizz.com> —— 注册、拿密钥、看名单、撤销
- 插件手册：[plugins/addons/blacklist/README.md](../plugins/addons/blacklist/README.md) ——
  装哪儿、每一项配置什么意思、拦截原理、常见问题
- 装法：[install.md](install.md)

全程十分钟左右。

---

## 一、注册平台账号、拿密钥（约 3 分钟）

1. 打开 <https://aiapizz.com> 注册（填 QQ 号，验证码发到你那个 QQ 邮箱）；
2. 登录后进「**用户中心**」，那里有一串 **32 位接口密钥**，复制出来；
3. 接口地址用 `https://aiapizz.com/api` —— 填到 `api` 这一层，结尾带不带斜杠都行。

这把密钥代表你的账号，别发群里、别写进能被人下载的文件。怀疑泄漏了就在用户中心点「重置密钥」，
然后到插件配置里换成新的（旧的立刻失效）。

## 二、装插件、填配置（约 5 分钟）

装法见 [install.md](install.md)。装完在「插件管理 → 配置」里填：

| 配置项 | 填什么 |
|---|---|
| **平台接口地址** | `https://aiapizz.com/api` |
| **平台接口密钥** | 用户中心那串 32 位密钥 |
| **下发拦截** | **默认开**：把平台的黑名单写进本站系统的黑名单表，付款时由系统自己拦住。只想上报、不想拦人就关掉 |
| 付款路径同步间隔 | 默认 10 秒。**这个数基本就等于「平台上拉黑一个人 → 本站拦住他」的时间** |
| 投诉处理时上报平台 | 建议开。系统处理买家投诉时上报，带订单号和投诉原文 |
| 同步跳过名单 | 测试账号、自己公司的 IP 这类，填进来：上行不报、下行也不拦 |

保存之后点一下「**测一下连接**」，再点一次「**立即同步**」。插件页第一张卡上那行数字
（本站在拦多少条、平台有效多少条、上次同步时间）动起来，就通了。

## 三、之后就不用管了

同步是自动跑的，三条路抢同一把锁，谁先到算谁的：

1. **系统计划任务**里的「公共黑名单同步」（`blacklist_sync`，60 秒一轮，上报和下发两个方向都做）；
2. **每个请求顺手同步一次**：付款相关页面 10 秒一档、其它页面 60 秒一档 —— **秒级拦截靠的就是这一路**；
3. 系统的**每日定时任务**兜一次底。

插件页那个「立即同步」按钮，只在「我刚在平台上拉黑了谁、想马上确认本站也拦上了」的时候点。

## 四、我们上报了什么（边界写清楚）

- 只报这些：**账号 / 手机号 / IP** 和拉黑天数；投诉类的再带上**订单号、买家账号/手机号/下单 IP、投诉正文**；
- **不报图片**，也不报买家的其它资料；
- 只在你**本地拉黑了这个人**、或者系统**处理投诉自动拉黑**的时候才报；
- 不想报的填进「同步跳过名单」；
- 平台侧单次最多计 **180 天**（你本地封多久是你自己的事），同一个人被反复上报时平台那边累计叠加，
  条目被撤销之后，所有接入站点的下一个支付请求立刻放行。

## 五、拦错了怎么办

**本站拦住了某个人，想放行**

- 只放行这一处：后台「交易管理 - 黑名单管理」里把备注为 `公共黑名单#编号` 的那一行删掉。
  插件**不会把它补回来**（你手动删掉，就是一种表态）；
- 以后都不想按平台名单拦：把「下发拦截」关掉，再去插件页「设置 → 维护」点一次「清空平台已下发条目」。

**这条名单本身就不该存在**

去官方 QQ 群 **439392221**，或者通过官网反馈。平台侧撤销之后，所有接入站点的下一个支付请求立刻放行。

## 六、出问题了先看哪儿

| 现象 | 先看 |
|---|---|
| 本站没拦住人 | 插件页第一张卡的状态是不是「只上报不拦截」；配置里「下发拦截」开着没有 |
| 平台没收到上报 | 插件页点「立即同步」，结果会写清成功几条、失败几条和原因；投诉类必须是**有真订单**的 |
| 上一轮没连上平台 | 地址密钥对不对（点「测一下连接」）、服务器能不能出网、平台在不在维护 |
| 计划任务里没有那条任务 | 插件页「自动同步」卡片上有「加进系统计划任务」按钮；老站没有计划任务表时，改用「访问URL」那条路 |

更细的（每一项配置、拦截原理、系统里到底改了哪些数据）在
[插件自带的 README](../plugins/addons/blacklist/README.md) 和官网文档中心 <https://aiapizz.com/docs.php>。
